# Data Analyst Survey Analysis

## Project Overview

This project explores survey data collected from Data Analysts to identify trends in demographics, salaries, job satisfaction, programming languages, and career experiences within the data analytics profession. The objective was to clean, analyze, and visualize the data to uncover meaningful insights and present them through an interactive dashboard.

## Tools Used

* Microsoft Excel
* Power BI

## Data Preparation

* Cleaned and transformed raw survey data in Excel.
* Handled missing values and inconsistencies.
* Standardized data formats to improve analysis accuracy.
* Prepared the dataset for visualization and reporting.

## Dashboard Development

Using Power BI, I developed an interactive dashboard that enables users to explore:

* Salary trends among Data Analysts
* Job satisfaction levels
* Preferred programming languages
* Demographic characteristics of respondents
* Career and industry insights

## Key Insights

* Identified the most commonly used programming languages among Data Analysts.
* Analyzed factors influencing job satisfaction.
* Explored salary variations across different respondent groups.
* Highlighted trends that can support career planning and industry understanding.

## Outcome

The project demonstrates practical skills in data cleaning, data transformation, data visualization, and dashboard development. The resulting dashboard provides a clear and interactive view of survey findings, enabling users to make data-driven observations about the Data Analytics profession.
